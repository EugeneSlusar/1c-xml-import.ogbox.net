# Описание проекта

Проект создаёт самостоятельную внешнюю обработку 1С `ЗагрузкаУПД.epf`. Она принимает XML универсального передаточного документа (УПД/ЭДО), нормализует данные, показывает их пользователю, сопоставляет с существующими объектами 1С и в целевой конфигурации создаёт непроведённый документ `РеализацияТоваровУслуг`.

## Целевые среды

- продуктивная: 1С:Управление торговлей 11.5.24.43, платформа 8.3.27;
- локальная проверка XML Reader: 1С:Управление нашей фирмой 3.0.12.237, платформа 8.3.27.1936;
- формат первой версии: `ВерсФорм=5.03`, `КНД=1115131`, `Функция=СЧФДОП` на реальном контрольном XML из `tests/samples`.

УНФ используется только как полигон загрузки, разбора и отображения XML. Создание реализации в УНФ не разрабатывается.

## MWP

Минимально работоспособный продукт состоит из двух последовательно принимаемых контуров:

1. безопасный XML Reader: выбор клиентского XML, чтение, валидация, нормализация и отображение шапки, строк и итогов; кнопка создания реализации выключена;
2. адаптер УТ: сопоставление существующих объектов, создание и запись непроведённой реализации с последующим открытием формы пользователю.

Первая инженерная контрольная точка — полностью работающий XML Reader в УНФ. До его приёмки разработка записи документов УТ не начинается.

## Архитектура

Поток данных разделяется на независимые части:

```text
XML -> UpdXmlParser -> NormalizedDocument -> UTMapper -> UTDocumentCreator
```

- `UpdXmlParser` знает структуру поддерживаемого XML, но не метаданные УТ;
- `NormalizedDocument` хранит исходные значения документа, сторон, строк и итогов без потери цены и сумм XML;
- `UTMapper` ищет только существующие организацию, контрагента, номенклатуру и единицы;
- `UTDocumentCreator` содержит проверенный на целевой базе код создания реализации.

## Ограничения и безопасность

Первая версия не создаёт элементы справочников, не проводит документы, не изменяет типовую конфигурацию, не подключает расширение и не перезаписывает существующие реализации. Цена, сумма без НДС, ставка НДС, НДС и сумма с НДС сохраняются раздельно; равенство `Цена × Количество = СуммаБезНДС` не предполагается.

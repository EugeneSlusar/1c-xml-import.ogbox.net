# Среды разработки и эксплуатации

Эти среды имеют разное назначение и не взаимозаменяемы.

| Понятие | Конфигурация | Платформа | Разрешённое назначение |
|---|---|---|---|
| Локальный toolchain | — | 8.3.27.1936 | Конфигуратор, bootstrap, выгрузка исходников, сборка EPF |
| Локальный тестовый стенд | УНФ Базовая 3.0.12.237 | 8.3.27.1936 | Форма, выбор файла, XML Parser, нормализация, валидация, отображение, ошибки |
| Целевая система клиента | УТ Базовая 11.5.24.43 | 8.3.27.1688 | Сопоставление объектов УТ и создание `РеализацияТоваровУслуг` |

## Жёсткие границы

1. Структура документов и справочников УНФ не используется для проектирования слоя УТ.
2. Создание документов УНФ не реализуется.
3. В УНФ команда создания реализации отключена или возвращает сообщение: `Создание документа поддерживается только в 1С:Управление торговлей 11.5.`
4. Все решения по организации, партнёру, контрагенту, соглашению, складу, табличным частям, ценам, НДС и записи документа подтверждаются на УТ Базовая 11.5.24.43.
5. Сборка на 8.3.27.1936 допустима, но выполняемый код и API должны быть совместимы с 8.3.27.1688.
6. UT-specific код окончательно принимается только на тестовой копии клиентской базы.

## Архитектурное следствие

Конфигурационно-независимый контур `XML -> Parser -> NormalizedDocument -> UI` разрабатывается локально в УНФ. Контуры `UTMapper -> UTDocumentCreator` изолируются от него и реализуются после получения доступа к реальным метаданным целевой УТ.

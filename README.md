# Загрузка УПД XML в 1С

Внешняя обработка `ЗагрузкаУПД.epf` загружает XML УПД/ЭДО, показывает нормализованные данные и в 1С:Управление торговлей 11.5 создаёт непроведённую `РеализациюТоваровУслуг`. Типовая конфигурация не изменяется.

Подробности: [описание проекта](docs/PROJECT.md) и [план разработки MWP](docs/DEVELOPMENT_PLAN.md).

## Среды

- целевая система клиента: **УТ Базовая 11.5.24.43**, платформа **8.3.27.1688**;
- локальный стенд: **УНФ Базовая 3.0.12.237**, платформа **8.3.27.1936**;
- Windows PowerShell 5.1+, Git, Конфигуратор 1С;
- BSL Language Server рекомендуется для проверки `.bsl`.

Локальная УНФ используется только для XML Parser, управляемой формы, валидации и обработки ошибок. Она не является моделью метаданных УТ. Код создания `РеализацияТоваровУслуг` проектируется и окончательно проверяется только по реальным метаданным УТ 11.5.24.43. API обработки должен быть совместим с платформой клиента 8.3.27.1688, хотя сборка локально выполняется платформой 8.3.27.1936. Полная матрица приведена в [описании сред](docs/ENVIRONMENTS.md).

## Структура

```text
src/             иерархическая XML-выгрузка внешней обработки
tests/samples/   контрольные XML УПД
scripts/         bootstrap, сборка и обратная выгрузка
config/          общие и локальные настройки
dist/            локальные бинарные EPF (не хранятся в Git)
docs/            описание и план
```

## Первый запуск

Локальные пути находятся в игнорируемом `config/local.settings.json`. Для другой машины скопируйте `config/local.settings.example.json` и исправьте пути.

```powershell
.\scripts\bootstrap.ps1
```

Если исходников ещё нет, скрипт выводит однократные действия в Конфигураторе: создать внешнюю обработку с управляемой формой, сохранить её в `dist`, затем выгрузить:

```powershell
.\scripts\dump.ps1
```

Сборка EPF из текстовых исходников:

```powershell
.\scripts\build.ps1
```

Команду без запуска 1С можно проверить так:

```powershell
.\scripts\build.ps1 -DryRun
.\scripts\dump.ps1 -DryRun
```

Скрипты используют штатные параметры платформы `LoadExternalDataProcessorOrReportFromFiles` и `DumpExternalDataProcessorOrReportToFiles` с иерархическим форматом.

## Проверка Milestone 1

1. Добавить контрольный XML в `tests/samples` под именем из `config/project.json`.
2. Собрать `dist/ЗагрузкаУПД.epf`.
3. В УНФ открыть обработку через `Файл -> Открыть` под пользователем с правом запуска внешних обработок.
4. Выбрать XML и сверить реквизиты, одну строку и итоги с критериями из плана.
5. Убедиться, что создание реализации недоступно и база не изменена.

При запуске в УНФ команда создания документа должна быть отключена или сообщать: `Создание документа поддерживается только в 1С:Управление торговлей 11.5.`

Создание справочников, проведение, корректировочные УПД, маркировка, ZIP, API и интеграция с оператором ЭДО в первую версию не входят.
